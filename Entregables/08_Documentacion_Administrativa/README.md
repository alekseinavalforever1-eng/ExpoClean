# 📁 08 — Documentación Administrativa

> Esta documentación solo se necesita **si el equipo gana**. Pero es bueno tenerla preparada.

## Documentos Requeridos (según Anexo 9 del Manual)

| # | Documento | Estado |
|---|---|---|
| 1 | Ficha de identificación del equipo (nombres completos) | ☐ Pendiente |
| 2 | Copia de documentos de identidad vigentes | ☐ Pendiente |
| 3 | Designación del representante o responsable administrativo | ☐ Pendiente |
| 4 | Ficha técnica y versión final del proyecto | ☐ Se genera del contenido de las otras carpetas |
| 5 | Declaración de autoría, originalidad y legitimidad de uso de recursos | ☐ Pendiente |
| 6 | Declaración de aceptación del premio y condiciones | ☐ Pendiente |
| 7 | Datos bancarios y certificación de cuenta | ☐ Pendiente |
| 8 | Documentación tributaria / comprobantes | ☐ Pendiente |
| 9 | Autorizaciones de uso de imagen | ☐ Pendiente |

## Nota

Los formatos de estos documentos probablemente serán proporcionados por la organización. Solo hay que tener los datos listos:
- Nombres completos de todos los integrantes
- Números de cédula
- Datos bancarios de quien recibiría el premio
- RUC o RISE (si aplica)
